This file cannot be generated for you — google-services.json is tied to
your specific Firebase project (API keys, project ID, app ID) and is
downloaded from the Firebase console, not something that can be authored
generically.

Steps:
1. https://console.firebase.google.com → your project (reuse Talksy's, or
   create a new one for TINA)
2. Project settings → your apps → Android app → register applicationId
   "com.tinaai.app" (must match app/build.gradle.kts exactly)
3. Download google-services.json
4. Do NOT commit it to git — it's project-specific and typically kept out
   of version control. Instead:
   - Locally/for sideload builds: place it directly at app/google-services.json
   - For the GitHub Actions build in this repo: copy its full contents into
     a repository secret named GOOGLE_SERVICES_JSON (Settings → Secrets
     and variables → Actions → New repository secret). The workflow writes
     it to app/google-services.json at build time.
5. Add app/google-services.json to .gitignore (already done in the
   .gitignore in this project).
